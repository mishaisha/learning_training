"Rather X THAN Y" trap: The thing AFTER "than" is the WORST error.
"Rather have 100 false alarms THAN miss 1 cancer" → MISS = Recall
"Rather reject 100 qualified THAN admit 1 unqualified" → FALSE ALARM = Precision
Definition P→P rule: Predicted → Precision. Real → Recall.
"Of all emails flagged as spam..." = Predicted = P → Precision
"Of all actual cancer cases..." = Real = R → Recall
Keywords: "catch/miss/never let through" → Recall. "false alarm/falsely accuse/wrongly flag" → Precision.
Mnemonic: Recall = CATCH ALL. Precision = BE PICKY. Accuracy = useless for imbalanced data.
