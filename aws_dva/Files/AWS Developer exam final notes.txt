AWS Organizations Service Control Policy (SCP) – Use an AWS Organizations Service Control Policy (SCP) to define the maximum permissions for account members of an organization 
or organizational unit (OU). 

SCPs limit permissions that identity-based policies or resource-based policies grant to entities (users or roles) within the account, but do not grant permissions.

Permissions boundary - Permissions boundary is a managed policy that is used for an IAM entity (user or role). 
The policy defines the maximum permissions that the identity-based policies can grant to an entity, but does not grant permissions.

Resource-based policy - The most common examples of resource-based policies are Amazon S3 bucket policies and IAM role trust policies.

Lambda - Event Source Mapping: (Services that Lambda reads events from)
- Applies to Kinesis Data Streams, DynamoDB and SQS
- Lambda function is invoked synchronously and records need to be polled from the service
- An event source mapping uses permissions in the function's execution role to read and manage items in the event source
- The configuration of the event source mapping for stream-based services (DynamoDB, Kinesis and Amazon SQS) is made on the Lambda side.

Note: For other services, such as Amazon S3, SNS, CloudWatch, Lambda function is invoked asynchronously and the configuration is made on the source (S3/SNS) rather than Lambda.

S3 Encryption:
SSE-S3: 
- encrypts objects using keys handled & managed by S3
- Must set header x-amz-server-side-encryption:aws-256

SSE-KMS:
- leverages AWS KMS
- Must set header x-amz-server-side-encryption":"aws-kms"
- With SSE-KMS, the encryption happens in AWS, and the encryption keys are managed by AWS, but you have full control over the rotation policy of the encryption key. 

SSE-C: 
- Encryption using data keys fully managed by the customer outside of AWS
- HTTPS must be used

Client Side Encryption:
- Clients must encryot data before sending to S3
- Customer fully manages the keys and encryption cycle
