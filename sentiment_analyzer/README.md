# Sentiment Analyzer - AI Learning Journey Project

This project demonstrates my progression in AI/ML learning through a sentiment analysis tool that classifies text as positive, negative, or neutral.

## Learning Milestones

### Milestone 1: Rule-Based Approach
- Simple word counting using positive/negative word lists
- No machine learning involved
- Shows understanding of basic text processing

### Milestone 2: Machine Learning Approach
- Trained Naive Bayes classifier on movie review dataset
- Uses scikit-learn for model training and evaluation
- Demonstrates ML pipeline understanding

### Milestone 3: Web Interface
- Interactive Streamlit app for real-time sentiment analysis
- Visual feedback with color-coded results
- Shows full-stack application skills

## Files
- `rule_based.py` - Milestone 1 implementation
- `ml_approach.py` - Milestone 2 implementation  
- `streamlit_app.py` - Milestone 3 implementation
- `requirements.txt` - Dependencies
- `sample_reviews.txt` - Test data

## How to Run
1. Install dependencies: `pip install -r requirements.txt`
2. Run rule-based: `python rule_based.py`
3. Run ML approach: `python ml_approach.py`
4. Run web app: `streamlit run streamlit_app.py`
